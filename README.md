# pairwise-soft-particle-depth

粒子雨落到地面时，离地越近反而越亮，软粒子淡出系数用了粒子的世界深度而不是场景深度；深度纹理在 MSAA 下是多重采样，采样单点取到边缘像素，粒子边缘出现锯齿状硬切；粒子系统用加法混合，淡出乘在颜色上而不是 alpha，近距离粒子叠加后过曝；半透明排序按粒子发射器排序而不是按粒子，同一发射器的粒子互相遮挡错序；深度预通道写了粒子的深度，主通道软粒子采样到自己，所有粒子都自淡出到零；相机近平面变化后深度线性化参数没更新，淡出距离整体偏移；粒子在屏幕边缘被裁剪，深度采样越界返回 1，边缘一圈粒子全消失；GPU 粒子的深度在顶点着色器里算，软粒子在片元里再算一次，两套插值不一致；粒子生命周期末尾缩放到 0，淡出距离也跟着缩，最后一帧突然变硬；多相机分屏时深度纹理只绑了主相机，副相机视角下软粒子全部穿帮。render/soft_particle_depth.py 是核心，tests/test_soft_particle_depth.py 15个红。要修的是：场景深度与粒子深度分离；MSAA 解析后采样；淡出作用于 alpha；按粒子排序；预通道跳过粒子；线性化随近平面；越界钳制；深度统一来源；缩放不影响淡出；按相机绑深度。

## 运行

```bash
python -m pytest tests -q
```
